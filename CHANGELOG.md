# Changelog

## 1.0.0

First public release.

- Copy a file's hash to the clipboard (MD5, SHA-1, SHA-256, SHA-384, SHA-512, CRC32), single or multiple files, one or all algorithms.
- Hash of a file at any commit, branch or tag, compared with the file on disk.
- Hash history table across all commits of a file, with the commit matching the disk file marked.
- Find a commit by hash; algorithm auto-detected by length; matches highlighted without hiding other commits.
- Shows both the repository hash and the after-checkout hash when line endings differ (CRLF).
